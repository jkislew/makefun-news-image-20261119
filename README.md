One page, one day: "The World in One Day" compresses Thursday 19 November 2026 into a single 1024x1024 front page painted entirely by a Python program. The lead story is the Gulf flaring up again — an American strike on Qeshm Island, Iranian fire aimed at bases in Kuwait, Bahrain intercepting for the third time in a week, and the Houthis back at Bab el-Mandeb. Under it sit the Shenzhen trilateral between Trump, Xi and Putin, Anthropic's record-breaking $81.3bn IPO priced at $83, a €45 billion EU loan for Ukraine, Voyager 1 crossing the one-light-day mark, and GTA VI's midnight arrival in Vice City, while a ticker along the foot of the page picks up the hawkish Fed minutes, the Bangladesh lockdown, Gaza and the Crimea Bridge. Running the program republishes the shipped page at /output/entry.png, byte for byte, on every run; `make_image.py` is the deterministic generator that painted the page when the entry was built.

## Run it

```sh
python3 main.py
```
